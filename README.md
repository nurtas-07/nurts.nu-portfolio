# Telegram-бот-портфолио «Обо мне»

Telegram-бот-портфолио «Обо мне» — заменяет классическое текстовое/сайтовое портфолио на интерактивного бота с навигацией по разделам, галереей хакатонов и встроенным ИИ, который отвечает на вопросы обо мне от первого лица.

Проект сделан в рамках курса Middle Python в **CapEducation**.

## 📦 Что внутри

Бот раскрывает портфолио через 8 разделов:

| Раздел | Команда |
|---|---|
| О себе | `/about` |
| Моя цель | `/goal` |
| Как я пришёл в IT | `/howistarted` |
| Мой ментор | `/mentor` |
| Точка А → Точка Б | `/progress` |
| Хобби и интересы | `/hobbies` |
| Мои лучшие работы | `/works` |
| Ссылка на GitHub | `/github` |

Плюс два дополнительных раздела:

- **🏆 Достижения** — список наград с хакатонов и научных конкурсов
- **🔥 Вайб хакатонов** — фотогалерея и истории с конкретных хакатонов (Just Build It, FutureTech, KazRobotics и др.)

---

## 🛠 Технологии

- Python 3.11+
- [`pyTelegramBotAPI`](https://github.com/eternnoir/pyTelegramBotAPI) — Telegram Bot API
- `python-dotenv` — переменные окружения
- `re` — валидация пользовательского ввода и парсинг команд
- `sys.argv` — аргументы командной строки при запуске

## 📁 Структура проекта

```
nurtas-portfolio-bot/
├── main.py              # точка входа, запуск polling
├── config.py            # sys.argv, переменные окружения
├── handlers.py          # обработчики команд и кнопок
├── keyboards.py         # inline-клавиатуры
├── content_loader.py    # загрузка content.json / hackathons.json
├── validators.py        # regex-валидация ввода
├── data/
│   ├── content.json     # тексты всех разделов
│   └── hackathons.json  # описания и фото хакатонов
├── media/
│   └── hackathons/       # фото с хакатонов
├── .env.example
├── requirements.txt
└── README.md
```

Контент полностью отделён от логики — все тексты лежат в `data/*.json`, а не захардкожены в коде.

## 🚀 Установка и запуск

Для запуска бота вам понадобятся установленные на компьютере **Python** (версии 3.11 или выше) и **Git**.

### Шаг 1. Скачивание проекта
Откройте терминал (или командную строку `cmd` / `PowerShell`) и скачайте проект:
```bash
git clone https://github.com/USERNAME/nurtas-portfolio-bot.git
cd nurtas-portfolio-bot
```

### Шаг 2. Виртуальное окружение (рекомендуется)
Создайте и активируйте виртуальное окружение, чтобы библиотеки бота не конфликтовали с другими программами:
```bash
# Создание
py -m venv venv

# Активация на Windows
venv\Scripts\activate

# Активация на Mac/Linux
source venv/bin/activate
```

### Шаг 3. Установка библиотек
Установите необходимые библиотеки (`pyTelegramBotAPI` и `python-dotenv`) одной командой:
```bash
pip install -r requirements.txt
```
*(Либо можно установить вручную: `pip install pyTelegramBotAPI python-dotenv`)*

### Шаг 4. Настройка токена
1. Создайте файл с названием `.env` в главной папке проекта.
2. Откройте его в любом текстовом редакторе (например, в Блокноте) и добавьте свой токен:
```env
BOT_TOKEN=8899244718:AAHiwj3Z7Qgf2ABDs1IxtBgSztoHSHu4Nzs
```

### Шаг 5. Запуск бота
Теперь всё готово! Запустите бота командой:
```bash
py main.py
```

### Аргументы командной строки

| Флаг | Описание |
|---|---|
| `--debug` | подробное логирование входящих сообщений в консоль |
| `--mode=polling` | режим запуска (по умолчанию) |

Пример: `py main.py --debug`

## 💬 Команды бота

| Команда | Действие |
|---|---|
| `/start` | приветствие и главное меню |
| `/about`, `/goal`, `/mentor` ... | переход к конкретному разделу |
| `/hack <slug>` | быстрый переход к конкретному хакатону, например `/hack future_tech` |

Навигация также полностью доступна через inline-кнопки — команды не обязательны.
